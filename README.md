# MicroProjects

**MicroProjects** is a curated collection of small, self-contained single-file projects and scripts designed for use with Creative Applications.

## About

Each project in this repository is intentionally minimal — one file, one purpose. Whether you're automating a repetitive task, extending the capabilities of a creative app, or experimenting with a new idea, you'll find ready-to-use scripts that get straight to the point.

## What's Inside

- 🎨 **Creative App Scripts** — Utilities and helpers for popular creative applications
- 🔧 **Single-File Tools** — Every project is self-contained; no complex setup or dependencies
- 💡 **Proof-of-Concepts** — Small experiments and ideas worth preserving

## Usage

Browse the repository and pick any script that fits your needs. Each file is standalone and can be dropped into your project or run directly.

## Contributing

Have a micro project to share? Feel free to open a pull request. Keep it to a single file and make sure it targets a creative app use case.
